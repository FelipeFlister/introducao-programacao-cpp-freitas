# Introdução à Programação - Curso em C++

Este repositório contém as minhas resoluções dos exercícios propostos no livro **"Introdução à Programação: Curso em C++"** do Dr. Alan R. R. de Freitas.

## 🚀 Objetivo
O foco deste projeto é praticar os fundamentos da linguagem C++ e lógica de programação através dos desafios teóricos e práticos da obra.

## 📁 Estrutura do Repositório
O código está organizado por capítulos e exercícios seguindo a numeração do livro:

* `capitulo-03/` -> Exercícios sobre [Assunto do Cap 3, Operadores básicos]
* `capitulo-05/` -> Exercícios sobre [Assunto do Cap 5, Operador de endereço e arranjos]

## 🛠️ Tecnologias
* C++ (padrão C++11 ou superior)
* Compilador GCC / Clang
